# SALESTORM Frontend Cockpit

Interactive Real-Time Dashboard for the SALESTORM Flash Sale Engine.

## Files
- `index.html` — Flash Sale Cockpit UI, real-time metrics display, live activity feed, inventory gauges.
- `style.css` — High-tech dark-mode cyber styling, responsive layout, animations.
- `app.js` — WebSocket live stream client, REST API integration, instant checkout simulator.

## Running
The frontend files are served directly by the backend Express server at `http://localhost:3000/`.
Alternatively, you can open `index.html` via any static file server (e.g. `npx serve .` or VS Code Live Server).
